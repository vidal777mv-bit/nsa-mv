## Interpretation

Profile uses these aligned display grids; heights are relative to each disk mean. Both surfaces share the pair exaggeration. Terrain layers use destination-specific mission thresholds. No scientific score is recomputed.

The atlas distinguishes detailed named sites from measured windows without detailed terrain exports. Source labels distinguish NASA elevation, derived measurements, and external place/climate context. Existing provenance reports remain the source-verification record; UI QA is not independent scientific validation.
